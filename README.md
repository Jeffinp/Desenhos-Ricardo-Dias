# Desenhos Ricardo Dias

<img src="https://github.com/Jeffinp/Desenhos-Ricardo-Dias/blob/main/imagens/icon.ico" alt="Logo" width="150" height="150">

Desenhos Ricardo Dias is a website I created for a client who is a drawing teacher. The site focuses on optimization, SEO, accessibility, speed, smooth navigation, and an attractive design. It features well-defined sections aimed at engaging various types of students interested in learning how to draw.

## Features

- A homepage with information about the teacher and his work
- A "Who Can Learn?" section tailored for different types of students
- A gallery showcasing students' drawings
- A blog for articles and drawing tutorials
- A contact form for inquiries and registrations

## Technologies Used

- HTML5
- CSS3
- JavaScript

## Installation and Usage

### Prerequisites

Make sure you have a modern, up-to-date browser.

### Installation Steps

1. Clone the repository:
   ```bash
   git clone https://github.com/Jeffinp/Desenhos-Ricardo-Dias.git
   ```
2. Navigate to the project directory:
   ```bash
   cd Desenhos-Ricardo-Dias
   ```
3. Open the `index.html` file in your browser.
